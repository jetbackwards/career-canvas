# Contributing to Career Canvas

Thank you for considering an improvement to Career Canvas.

## Before contributing

- Search existing issues and pull requests before starting work.
- For substantial changes, open an issue first so the approach can be discussed.
- Never commit real CVs, backups, import files or personally identifiable career data.
- Keep the application self-hosted and avoid adding external services, analytics or web fonts without prior discussion.

## Making a change

1. Fork the repository and create a focused branch.
2. Make the smallest coherent change.
3. Run the syntax checks:

   ```bash
   npm run check
   ```

4. Test the affected workflow locally, including printed PDF output where relevant.
5. Open a pull request explaining the problem, the change and how it was tested.

## Licensing contributions

By submitting a contribution, you agree that it is licensed under `AGPL-3.0-only` with the additional attribution term in [ATTRIBUTION.md](ATTRIBUTION.md). You retain copyright in your contribution.

The original-creator attribution must remain intact. This does not prevent contributors from identifying and receiving credit for their own work; substantial contributors may add themselves to [AUTHORS.md](AUTHORS.md).

## Conduct

Be constructive, respectful and mindful that this project may be used with sensitive professional information.
